# ml-cardio-project / КардиоПрогноз — локальный MVP

Исследовательский Flask-сервис, который выдаёт оценку **вероятности класса наличия сердечного заболевания в разметке UCI Cleveland**. Это **не** медицинский диагноз и **не** прогноз риска инфаркта/события через несколько лет. Нельзя применять результаты для клинического решения.

## Текущее содержание

- Flask-форма для 13 признаков + кнопка примера/очистки.
- `POST /predict`: серверная валидация -> sklearn Pipeline -> вероятность класса -> 3 локальных SHAP-фактора.
- `GET /health`: базовая доступность процесса.
- `tests/`: 50 синтетических сценариев, отрицательные проверки, отдельные тесты безопасности ввода.
- `.github/workflows/`: CI-тестирование и сканирование зависимостей/секретов.
- `docs/`: исходные материалы репозитория (ADR/Kanban и диаграмма зависимостей), проектный статус, аудит архива, бэклог и инструкция GitHub.

### Модель и данные

- Источник в метаданных: UCI Heart Disease (Cleveland), данные в `data/heart_cleveland.csv`.
- 13 входных признаков; целевая метка — наличие заболевания в исходном датасете.
- Артефакт `models/heart_model.joblib` был сохранён со scikit-learn **1.6.1**. Он загружается через joblib/pickle: использовать только доверенный локальный файл.
- В `data/metrics.json` сохранены результаты предыдущего обучения (`test_roc_auc`: 0.9665, `test_f1`: 0.8814, test=61). **В этом пакете метрики не пересчитывались**, клиническая достоверность не доказана. Перед публичным распространением уточнить условия использования исходного датасета.
- Интерфейс работает только с синтетическими примерами; не вводить идентифицирующие медицинские записи.

## Запуск (Windows PowerShell, Python 3.11)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Открыть `http://127.0.0.1:5000`.

> Если PowerShell блокирует активацию, можно без неё вызвать `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` и `.\.venv\Scripts\python.exe app.py`.

Проверка:

```powershell
python -m pytest -q
```

Если появилось предупреждение `InconsistentVersionWarning`, сначала сверить `python -m pip show scikit-learn` с `models/model_info.json`: модель была обучена версией `1.6.1`. Не «лечить» проблему путём подавления предупреждений; при смене версии переобучить и повторно сохранить модель с проверкой метрик.

## API

`POST /predict` с `Content-Type: application/json` и всеми 13 числовыми полями. Пример см. в `tests/test_mvp.py` (`BASE_CASE`). Ответ включает `probability`, `predicted_class`, `factors`, `warning`, `request_id`. Ошибки 400/413/500 включают `code` и `request_id`, сырые показатели в лог не записываются приложением.

## Безопасность

`SECURITY.md` описывает ограничения и сканирование. `debug=False`, локальный bind, ограничение JSON до 16 KiB — это базовые меры, но не защита для интернет-доступной медицинской ИС. Прямое развёртывание на сервер клиники и обработка персональных данных не разрешены.

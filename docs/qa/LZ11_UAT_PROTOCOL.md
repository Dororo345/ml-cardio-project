# ЛЗ 11 — протокол независимого пользовательского тестирования

**Статус: ожидает независимого проведения.** Автоматические тесты не заменяют этот протокол. Дата испытания, проверяющие и результаты появятся только после фактической сессии.

## Паспорт испытания

| Поле | Заполняется при проведении |
|---|---|
| Дата и время с часовым поясом | Не назначено |
| Проверяющий и команда | Не назначены |
| Представитель разработчиков (только наблюдение) | Не назначен |
| Адрес стенда / версия / commit SHA | Не указан |
| Тестовые учётные записи и набор данных | Синтетические; пароли в протокол не записывать |

## Замечания вне сценариев

Заполняются проверяющим и наблюдателем во время настоящего испытания. Для каждого замечания указать ожидаемое и фактическое поведение, приоритет, владельца, дату исправления и ссылку на GitHub Issue. Пока замечаний от независимого проверяющего **нет**.

## Решение о приёмке

**Не принято к независимой пользовательской приёмке**, поскольку UAT ещё не проводился. После выполнения сценариев проверяющий подписывает вывод: «принято» / «принято с оговорками» / «не принято» и указывает дату. Самостоятельно подставлять имя участника или задним числом ставить статусы запрещено.

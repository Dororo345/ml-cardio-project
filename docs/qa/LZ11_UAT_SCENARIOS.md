# ЛЗ 11 — пользовательские сценарии приёмки

**Продукт:** КардиоПрогноз V3. **Назначение:** инструкции для независимого участника, который впервые видит сайт. Проверяющий выполняет действия без подсказок разработчика. Использовать только вымышленные данные.

До старта организатор предоставляет ссылку на отдельный тестовый стенд, тестовый логин обычного пользователя и, для сценариев администратора, отдельный временный аккаунт администратора. Пароли в документ или протокол не вписывать. Создать тестовый файл командой из плана или взять `CardioPrognoz_V3/samples/lz11_synthetic_50.csv`.

| № | Действие человека | Ожидаемый результат и однозначный критерий |
|---|---|---|
| UAT-01 | Открыть сайт и войти с выданными правильными данными | Появилась страница ввода медицинских показателей; **пройдено**, если не показана ошибка входа |
| UAT-02 | Выйти и попробовать войти с неверным паролем | Доступ не предоставлен, видно понятное сообщение об ошибке; **пройдено**, если прогноз открыть нельзя |
| UAT-03 | Войти и заполнить все поля допустимыми числами из тестового примера, затем нажать «Рассчитать» | Показана вероятность 0–100 % и заметное предупреждение, что модель учебная; **пройдено**, если обе части есть |
| UAT-04 | Оставить обязательное поле пустым и нажать «Рассчитать» | Сайт просит заполнить поле и не показывает новый прогноз; **пройдено**, если ошибку можно исправить без подсказки |
| UAT-05 | Ввести явно недопустимый возраст и попытаться рассчитать | Понятное сообщение о неверном значении, нет ошибочно рассчитанного результата; **пройдено**, если отказ понятен |
| UAT-06 | Войти как обычный пользователь и попробовать открыть страницу управления аккаунтами | Панель администратора недоступна; **пройдено**, если список пользователей не показывается |
| UAT-07 | Войти как администратор и создать временную учебную учётную запись | Новая запись видна в списке; **пройдено**, если новая запись появилась и ей можно войти |
| UAT-08 | Скачать пример CSV, загрузить файл на странице интеграции | По строкам показаны результаты, пользователь понимает, какие строки приняты; **пройдено**, если нет общей ошибки загрузки |
| UAT-09 | Загрузить тестовый CSV с 45 верными и 5 ошибочными строками | 45 результатов и 5 ошибок с номерами строк; **пройдено**, если выявлены строки файла 11, 21, 31, 41, 51 |
| UAT-10 | Добавить в CSV столбец с именем пациента и попробовать загрузить | Файл целиком отклонён, показана причина; **пройдено**, если новые данные не обработаны |
| UAT-11 | Получить запись `SYN-001` из включённого локального тестового сервиса | Показаны 13 учебных показателей и их результат; **пройдено**, если данные получены без личных сведений |
| UAT-12 | Повторить получение записи при отключённом тестовом сервере | Понятная ошибка недоступности; **пройдено**, если сайт не зависает и не выдаёт выдуманный результат |
| UAT-13 | Нажать «Выйти» и попытаться снова открыть страницу интеграции | Предлагается войти заново; **пройдено**, если доступ без авторизации закрыт |

## Обязательные отрицательные проверки

UAT-02, 04, 05, 06, 10, 12, 13 специально проверяют неправильный пароль, пустые/неверные поля, отсутствие прав, нежелательный столбец, недоступный сервис и завершение сессии. Для строгого сценария «открыть чужую медицинскую запись» в V3 **нет сохранённых пациентских записей**, а операция «отклонить с причиной» не реализована: это **неприменимо к текущей версии** и должно быть добавлено в UAT при появлении соответствующих функций.

## Правила проведения

1. До начала сверить, что тестовые аккаунты и тестовый сервер работают.
2. Проверяющий читает задание и самостоятельно выбирает кнопки. Разработчик наблюдает и записывает, не подсказывает.
3. Для каждого сценария записать «пройдено», «не пройдено» или «не выполнялся», ссылку на дефект и комментарий.
4. Дополнительные затруднения, не вошедшие в сценарии, тоже записать.
5. Не выдавать автоматические Flask-тесты за независимый UAT.

## История пользователя
Администратор создаёт и отключает учебные аккаунты для управления доступом.

## Планирование
Спринт: S1. Оценка из ЛЗ 4: M. Исполнитель: Dororo345.
Код CARD — идентификатор истории ЛЗ 4, он не совпадает с номером GitHub Issue.

## Критерии приёмки
- [ ] Дано: вошёл администратор. Когда: создан уникальный логин и пароль длиной 10–128 символов. Тогда: аккаунт появляется в SQLite.
- [ ] Дано: логин уже существует. Когда: он введён в другом регистре. Тогда: дубликат отклоняется.
- [ ] Дано: обычный пользователь. Когда: он открывает /admin. Тогда: HTTP 403.
- [ ] Дано: администратор отключил пользователя. Когда: тот входит вновь. Тогда: вход отклоняется.
- [ ] Дано: POST без CSRF. Когда: выполняется изменение. Тогда: HTTP 400.

## Definition of Done
- [ ] Критерии проверены и приложены логи.
- [ ] Регрессия и CI прошли для того же commit.
- [ ] Документация обновлена, PR связан с Issue.
- [ ] Демонстрация на стенде подтверждена.
- [ ] Второй человек выполнил ревью.

По указанию владельца независимое ревью и двухнедельное наблюдение в текущую работу не входят. Это не означает, что требование методички уже выполнено. До подтверждения полного DoD карточка остаётся открытой.

## Критерии приёмки
- [ ] Дано: CSV UTF-8 с ровно 13 разрешёнными колонками. Когда: загружен файл. Тогда: для валидных строк рассчитаны вероятность и класс.
- [ ] Дано: неверные значения отдельных строк. Когда: обработан CSV. Тогда: ошибки перечислены с номерами, остальные строки рассчитаны.
- [ ] Дано: неизвестные или повторные поля либо отсутствующие колонки. Когда: проверен заголовок. Тогда: весь файл отклонён.
- [ ] Дано: более 50 строк либо более 64 КБ. Когда: выполняется импорт. Тогда: обработанная ошибка.
- [ ] Дано: CSV из 45 валидных и 5 неверных строк. Когда: выполнен импорт. Тогда: ровно 45 результатов и ошибки строк 11, 21, 31, 41, 51 (НФТ-19).

## Реализация и проверки
Код: `integration.py; app.py; templates/integration.html` в отдельном приложении `CardioPrognoz_V3/`.
Проверки: `test_upload_per_row_results; test_upload_unknown_columns_rejected; test_csv_rejects_more_than_50_rows; test_nft19_45_valid_and_5_invalid_rows`.
Исходный результат аудита: 85 passed / 5 failed. После исправления подготовки CSRF: 90 passed. Последующий расширенный прогон 115 passed; финальные результаты и CI публикуются в связанном PR. Рабочая версия корневого MVP сохраняется отдельно.

## Definition of Ready
- [x] История и проверяемые критерии сформулированы.

## Definition of Done
- [ ] Критерии проверены и приложены логи.
- [ ] Регрессия и CI прошли для того же commit.
- [ ] Документация обновлена, PR связан с Issue.
- [ ] Демонстрация на стенде подтверждена.
- [ ] Второй человек выполнил ревью.

По указанию владельца независимое ревью и двухнедельное наблюдение в текущую работу не входят. Это не означает, что требование методички уже выполнено. До подтверждения полного DoD карточка остаётся открытой.

## Политика потока
Backlog → Ready → In Progress → Waiting Review → Review → Testing → Done.
S1: In Progress ≤2 на исполнителя, Waiting Review ≤2, Review ≤1 (в сумме ревью ≤3), Testing ≤2.

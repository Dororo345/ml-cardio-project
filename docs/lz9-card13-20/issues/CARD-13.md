## Критерии приёмки
- [ ] Дано: активный пользователь. Когда: введены правильные логин и пароль. Тогда: создаётся сеанс и открывается форма.
- [ ] Дано: неверный пароль либо неизвестный логин. Когда: выполнен вход. Тогда: одинаковое сообщение «Неверный логин или пароль».
- [ ] Дано: гость либо завершённый сеанс. Когда: открыта форма или POST /predict. Тогда: редирект на вход либо HTTP 401.
- [ ] Дано: активный сеанс. Когда: аккаунт отключён. Тогда: следующий запрос теряет доступ.

## Definition of Ready
- [x] История и проверяемые критерии сформулированы.
- [x] Зависимости и синтетические данные определены.
- [x] Исполнитель указан, объём оценён S/M.
- [x] Реальная медицинская ИС и персональные данные исключены.

## Definition of Done
- [ ] Критерии проверены и приложены логи.
- [ ] Регрессия и CI прошли для того же commit.
- [ ] Документация обновлена, PR связан с Issue.
- [ ] Демонстрация на стенде подтверждена.
- [ ] Второй человек выполнил ревью.

По указанию владельца независимое ревью и двухнедельное наблюдение в текущую работу не входят. Это не означает, что требование методички уже выполнено. До подтверждения полного DoD карточка остаётся открытой.

## Политика потока
Backlog → Ready → In Progress → Waiting Review → Review → Testing → Done.
S1: In Progress ≤2 на исполнителя, Waiting Review ≤2, Review ≤1 (в сумме ревью ≤3), Testing ≤2.
S2: дополнительно общий активный WIP ≤1 — одно изменение модельной ретроспективы.

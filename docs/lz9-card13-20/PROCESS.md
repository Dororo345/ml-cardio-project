# ЛЗ 9 — политики для пяти историй КардиоПрогноз

Статус: политика опубликована с новым инкрементом. Текст не является доказательством изменения настроек Projects.

## Политики

| Статус | Вход | Выход |
|---|---|---|
| Backlog | Пользовательская история сформулирована | Уточнены критерии и зависимости |
| Ready | DoR выполнен и исполнитель назначен | Есть WIP-слот и работа началась |
| In Progress | Начата реализация или подготовка проверок | Код, первичные тесты и PR готовы |
| Waiting Review | PR готов к независимой проверке | Второй человек приступил к ревью |
| Review | Реальное независимое ревью | Блокирующие замечания устранены |
| Testing | Версия готова к приёмке на стенде | Тесты, CI, документация и объединение PR подтверждены |
| Done | Полный DoD выполнен | При дефекте переоткрыть с причиной |

## WIP
S1: In Progress ≤2 на исполнителя, Waiting Review ≤2, Review ≤1; Waiting Review + Review ≤3 на команду; Testing ≤2.
S2: единственное новое правило — общий WIP (In Progress + Waiting Review + Review + Testing) ≤1.
При заполненном лимите помогать закончить начатое. Заблокированные задачи продолжают учитываться в WIP.

## DoR
Польза, проверяемые Given–When–Then, зависимости, синтетические данные, оценка S/M, назначение исполнителя и способ проверки готовы. Объём помещается в спринт.

## DoD
Критерии и регрессия подтверждены логами; второй человек выполнил ревью; локальный стенд продемонстрирован; README обновлён; связанный PR объединён и CI прошёл для той же версии. Самопроверка не заменяет независимое ревью.

## События
Фактические переходы фиксировать в день действия в UTC с Issue URL, старым/новым статусом, источником и доказательством. Не переносить относительные часы из simulation в даты GitHub. Новые Issues оставлять открытыми до полного фактического DoD. Поля карточек для публикации: CARD, Sprint, Status, Size, Assignee; статус модели хранить отдельно и явно подписывать.

# Контракт /predict

POST с JSON и 13 числовыми признаками.

| HTTP | Смысл |
|---|---|
|200|Корректный прогноз; probability 0..1, predicted_class 0/1|
|400|Ошибочный JSON, поля, типы, диапазоны; code/error/request_id и fields, если известны|
|413|Тело более 16 KiB; PAYLOAD_TOO_LARGE|
|500|Модель не смогла вычислить конечную вероятность в диапазоне 0..1; PREDICTION_ERROR|

422 не используется: для совместимости текущей формы семантические ошибки также возвращают 400. Это уточнение контракта ЛЗ4, а не заявление о наличии 422. Ошибки не содержат прогноза. В журнал пишется только тип события и request_id, без входных показателей и текста исключения. Traceback исключён: сообщение исключения сторонней библиотеки может содержать входные данные.

## Независимость XAI
Успешный прогноз сохраняется при сбое объяснителя: HTTP 200, factors=[], xai_status=unavailable, xai_message с понятным сообщением. При успехе xai_status=available. Сбой самой модели остаётся 500. Никакие факторы не подставляются вместо SHAP. Ошибка инициализации объяснителя также допускает прогноз без объяснения.

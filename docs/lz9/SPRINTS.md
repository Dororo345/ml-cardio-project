## Как фиксировать работу
При смене состояния оставить комментарий `FLOW: ...` в Issue и одновременно переместить в колонку GitHub Projects. Закрывать только по DoD. Реальное время проставляет GitHub. Не восстанавливать вымышленные события прошлых недель.

# Приёмка второго инкремента

Цель: воспроизводимый прогноз с версией артефакта, честным состоянием XAI и безопасной очисткой формы.

`python scripts/lz9/synthetic_acceptance.py --out docs/lz9/evidence/synthetic_50.csv`

Результат: 50/50 passed; 40 положительных, 10 отрицательных; 50 уникальных входов. Запросы отправляются через настоящий HTTP к локальному Flask/Werkzeug-серверу. Проверяются код, request_id, вероятность, класс, версия модели, XAI; в негативных случаях — код ошибки и отсутствие прогноза. CSV содержит каждый синтетический ввод, ожидаемый/фактический код и результат. observed_utc — часы среды исполнения, не GitHub created_at; для метрик потока использовать только GitHub API.

`python -m pytest -q` — 118 passed. `npm test` — 4 DOM-теста прошли. Матрица 50 сценариев также выполняется в CI и сохраняется в test-results. Результаты не являются ручным UAT, клинической проверкой или замером медицинской точности.

# Проверка формы

`npm install --no-save jsdom`

`node --test tests/ui/*.test.cjs`

Тесты исполняют настоящий inline JavaScript формы в jsdom. Это автоматизированные DOM-тесты, не ручной браузерный UAT и не проверка визуального отображения.

Reset проверяется для всех 13 полей, текста ошибки, вероятности, класса, списка XAI, сообщения XAI и атрибутов aria-invalid. Отдельный тест задержанного ответа подтверждает: результат старого запроса не восстанавливает очищенную форму. Механизм — поколение запроса, которое меняется при Reset и заполнении примера.

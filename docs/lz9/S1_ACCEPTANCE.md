# Приёмка первого инкремента

Цель: пользователь получает проверенный прогноз для корректного ввода и понятную ошибку без фиктивного результата для некорректного.

Автоматические сквозные проверки используют настоящий HTTP-сервер Werkzeug на loopback и urllib: корректный ввод 200 (20,93%), неверный возраст 400, превышение размера тела 413. Проверяются JSON, request_id, no-store и отсутствие прогноза на ошибке. Команда: `python -m pytest -q tests/test_end_to_end.py` — 3 passed.

Общая проверка: `python -m pytest -q` — 112 passed; DOM-тест формы — 1 passed. Это автоматические проверки, не ручная пользовательская приёмка. Стенд локальный, не публичный production.

# Ретроспектива первого спринта

Формат: асинхронная ретроспектива одиночного исполнителя по выгрузке GitHub; не заявляется 30-минутная встреча команды.

Продолжать: тестировать негативные случаи, сохранять настоящие FLOW-события, объединять проверенные PR.

Прекратить: перекрывать работу над несколькими задачами.

Начать — ровно одно изменение: общий WIP всех активных статусов <=1; следующая задача берётся после Done предыдущей.

Владелец действия: исполнитель автоматизации; ответственный за проект Dororo345. Срок: все четыре задачи S2. Метрика принятия: 0 минут с WIP>1. Дополнительно сравниваются cycle time и throughput без гарантии улучшения.

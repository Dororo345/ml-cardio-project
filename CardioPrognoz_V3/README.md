# КардиоПрогноз — ЛЗ 9, спринт 2 (функции версии 3 из ЛЗ 4)

Продолжение работающего первого спринта. Сохранены: обязательная авторизация, создание/отключение пользователей, 13 показателей, ML-прогноз и SHAP, учебные предупреждения.

**Во втором спринте добавлены:**

- **CARD-19:** тестовый адаптер медицинской ИС через отдельный mock на `127.0.0.1:5001`, синтетические записи `SYN-001`–`SYN-020`;
- **CARD-20:** импорт CSV UTF-8 со строгим списком 13 полей, расчёт по каждой корректной строке, список ошибок по номерам строк. Неизвестные поля отклоняют весь файл.

Важно: это версия 3 **по Story Map в ЛЗ 4**. PDF/история/локализация — истории версии 2 (CARD-15/16/18), в данную сборку не включены. Никакие реальные данные пациентов не принимаются и внешние медицинские системы не подключаются; mock привязан к `127.0.0.1`. Импорт не сохраняет файлы в базу. Предсказания носят строго учебный характер.

## Запуск на Windows (Python 3.10–3.11)

Из папки проекта (там, где `app.py`) с подготовленным виртуальным окружением из первого спринта:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app init-db
.\.venv\Scripts\python.exe app.py
```

Если аккаунты уже есть в файле `instance/cardio.sqlite3`, **не нужно создавать админа заново**. **Внимание:** при распаковке архива в новую папку база SQLite из предыдущей папки сама не переносится. Её можно скопировать из `instance/cardio.sqlite3` предыдущей локальной установки **при остановленном сервере** (никогда не выкладывайте этот файл с паролями в GitHub), либо выполнить:

```powershell
.\.venv\Scripts\python.exe -m flask --app app create-admin admin
```

Пароль вводится в консоль, минимум 10 символов.

Для CARD-19 открыть **второй терминал в этой папке** и выполнить:

```powershell
.\.venv\Scripts\python.exe mock_medical_service.py
```

Откройте http://127.0.0.1:5000, войдите, перейдите **«Тестовая интеграция / импорт CSV»**. Для mock выберите SYN-001. Для импорта скачайте встроенный `synthetic_measurements.csv`, затем загрузите его обратно. Выключите второй терминал для демонстрации ошибки недоступного сервиса.

## Контракт импорта

CSV: разделитель `,`, первая строка — имена колонок, UTF-8, максимум 64 КБ и 50 строк данных. **Ровно эти колонки:**

```
age_years,sex_code,chest_pain_code,resting_bp,cholesterol,fasting_sugar_flag,rest_ecg_code,max_heart_rate,exercise_angina_flag,st_depression,st_slope_code,vessels_code,thal_code
```

Имена сопоставляются в `integration.py` с модельными `age,sex,cp,trestbps,chol,fbs,restecg,thalach,exang,oldpeak,slope,ca,thal`. Ошибочное значение в одной строке не прерывает проверку остальных. Неразрешённый столбец, включая `patient_name`, приводит к отклонению всего файла.

## Проверки после аудита ЛЗ 9
Новые аккаунты используют Argon2id; прежние хеши Werkzeug сохраняют совместимость и обновляются после успешного входа. Для полного перевода старых аккаунтов нужен их успешный вход; сброс паролей не выполняется. Mock содержит 20 разных детерминированных синтетических JSON-записей.

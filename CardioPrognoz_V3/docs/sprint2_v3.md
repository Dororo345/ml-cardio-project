# ЛЗ 9 · Спринт 2: учебная версия 3 по ЛЗ 4

## Цель спринта
Пользователь с действующей учётной записью может получить **синтетическую** запись от локального mock-сервиса и проверить импорт обезличенного CSV с расчётом по существующей ML-модели, не подключаясь к реальной медицинской ИС.

## Задачи из бэклога ЛЗ 4

### CARD-19 — локальный mock-адаптер
- [ ] Mock `127.0.0.1:5001` возвращает синтетические SYN-001–SYN-020.
- [ ] В приложении есть команда получить тестовую запись и рассчитать её.
- [ ] Все 13 внешних полей переведены в модельную схему.
- [ ] При остановленном mock пользователю показана обработанная ошибка.
- [ ] Никаких реальных сервисов и медицинских персональных данных.

### CARD-20 — тестовый CSV-импорт
- [ ] Загружается CSV UTF-8 из документированных 13 полей.
- [ ] Для корректных строк рассчитывается результат существующей ML-модели.
- [ ] Некорректные значения выводятся отдельно по номеру строки.
- [ ] Колонки вне разрешённой схемы отклоняют весь файл.
- [ ] Файлы и результаты не сохраняются, используются только синтетические данные.

Чекбоксы для дальнейшей *фактической* приёмки; наличие кода само по себе не означает проведённое UAT.

## Почему это версия 3, а не PDF
В ЛЗ 4 история прогнозов, PDF, локализация относятся к **версии 2** (CARD-15/16/18). Версия 3 — это **CARD-19/20**: mock-обмен и обезличенный импорт. Версия 3 здесь демонстрируется как **независимый учебный инкремент** поверх функциональности первого спринта. Он не объявляет все пункты версии 2 завершёнными.

## Для отчёта по ЛЗ 9
Переходы задач в GitHub Projects и timestamps фиксировать отдельно от тестового кода. Результаты throughput, p85, WIP, CFD и закона Литтла можно считать только из дат реальных или явно обозначенных **модельных** событий. После первого спринта оформить **одно** изменение процесса по ретроспективе и проверить его во втором.


## Проверки после аудита ЛЗ 9
Новые аккаунты используют Argon2id; прежние хеши Werkzeug сохраняют совместимость и обновляются после успешного входа. Для полного перевода старых аккаунтов нужен их успешный вход; сброс паролей не выполняется. Mock содержит 20 разных детерминированных синтетических JSON-записей.
